# Ідеї для наступних оновлень (власник обирає номери)

Мій рекомендований топ: **1, 6, 7, 11, 16, 19**.

## Ближче до справжнього відділення
1. Огляд посилки перед оплатою: бій / не та річ → відмова, повернення відправнику.
2. Повернення та переадресація (інше місто / інша людина).
3. Довіреність: «посилка для мами» — перевірити дозвіл, відмовити шахраям.
4. Оголошена вартість / документи для великих відправлень.
5. «Втрачена» посилка — міні-гра пошуку на складі.
6. Сканер штрихкодів — «пікати» посилку замість кліку по рядку.

## Події
7. Свята й розпродажі (Чорна п'ятниця, Новий рік, Валентина): потік посилок, подвійні машини.
8. Погода впливає на кількість клієнтів.
9. Перевірка регіонального менеджера — оцінка і премія.
10. Відключення світла: ручний режим, генератор як покращення.

## Розвиток
11. Щоденні завдання і досягнення з нагородами.
12. Кар'єра оператора (Оператор → … → Регіональний керівник).
13. Друге відділення в іншому місті.
14. Оформлення залу (стіни, рослини, плакати, кулер), видно іншим гравцям.
15. Риси/навички персоналу, настрій і втома.

## Онлайн
16. Відвідати відділення друга, залишити відгук.
17. Посилки між гравцями — подарунок приходить другу як реальна посилка для видачі.
18. Тижневий конкурс відділень зі значком.
19. Панель розробника для власника (оголошення, події, подарунки) — додати його player id у `np_admins`.

## Атмосфера
20. Анімований зал (двері, віконце, клієнт іде з посилкою).
21. Звуки: шум відділення, принтер ТТН, «Наступний!».
22. PWA — встановлення на телефон з іконкою.

Власник також може розповісти реальні ситуації з роботи оператором — їх варто перетворювати на механіки.
