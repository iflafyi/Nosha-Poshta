## Layout
- `index.html` — the whole game (HTML + CSS + one script). Edit it directly.
- `build.py [BUILD_ID]` — stamps `GAME_BUILD` in index.html and writes `version.json` (players get an "update available" bar). Run before every deploy.
- `config.js` — Supabase URL + publishable key.
- `sql/schema.sql` — snapshot of the online backend (reference; live DB is the truth).
- `src/hall3d.js` — 3D hall (Three.js 0.187, imports from 'three'); bundled into `hall3d.js` (repo root, loaded with `defer`, cached by sw.js). Rebuild after editing the source:
  `npm i --no-save esbuild three@0.187.0` (in a scratch dir) then `NODE_PATH=<dir>/node_modules <dir>/node_modules/.bin/esbuild src/hall3d.js --bundle --minify --format=iife --target=es2019 --legal-comments=none --outfile=hall3d.js`
- PWA: `manifest.webmanifest`, `sw.js` (network-first, cache fallback; never caches Supabase or version.json), `icon-192/512.png`, `apple-touch-icon.png`.

## Backend: Supabase project `nsdjlohfagslhfaygstp` (shared with the cat shelter game; this game uses only `np_*`)
- Tables: `np_players` (leaderboard stats, last_seen, `hall` jsonb shown to visitors, `rank`), `np_secrets` (sha256 of player secret), `np_saves` (state JSON + build), `np_chat`, `np_admins` (owner «Демчак Дмитро» `8ea1caa6-a072-4e4d-ab69-4de31a1ca816`), `np_reviews`, `np_gifts`, `np_week_res`/`np_week_claims` (weekly contest, ISO week UTC), `np_announce`, `np_global` (event/weather/insp/outage set by dev).
- All access via SECURITY DEFINER RPCs: `np_register(nick, branch, secret)`, `np_save(id, secret, state, build, stats)` (rejects older build → client reloads), `np_load`, `np_ping`, `np_top(sort)`, `np_chat_send`, `np_chat_recent(after)`. Client calls them with plain fetch (`rpc()`), only `apikey` header.
- v2 RPCs: `np_top` (+rank, hall, rev_avg, rev_n), `np_reviews_for`, `np_review`, `np_gift_send` (≤10/day), `np_gifts_pull`, `np_week_top`, `np_week_claim`, `np_announce_recent`, `np_global_get`; admin (`np_is_admin` check): `np_admin_announce`, `np_admin_ann_off`, `np_admin_global`, `np_admin_gift` (`dev:money:N`/`dev:xp:N`, to one or all), `np_admin_stats`, `np_admin_chat_del`. `np_load` returns `admin` → dev panel tab «🛠 Розробник» in Онлайн.
- Realtime broadcast channel `np-chat` (event `m`) for instant chat; polling as fallback.
- Save code in Settings = `NP-` + base64({i: player id, s: secret}) to move to another device (still works).
- Accounts (2026-11-01, `sql/accounts.sql`): `np_accounts` (email lowercased → player_id, bcrypt `pass_hash`, 5 fails → 10 min lock) + `np_sessions` (sha256 of a per-device secret; `np_check` accepts `np_secrets` OR `np_sessions`). RPCs: `np_acc_register(nick, branch, email, pass)` → {id, secret, email}; `np_acc_link(id, secret, email, pass)`; `np_acc_login(email, pass)` → {id, secret, email, nick} or {err:'wrong'|'locked'} (no raise, so the fail counter commits); `np_acc_info`, `np_acc_logout` (drops this device's session), `np_acc_pass(id, secret, old, new)`; admin `np_admin_acc_reset(id, secret, player, pass)` (drops all sessions). No email sending (no SMTP) → forgotten password = dev resets it in the dev panel.
- Client: `G.acc` = email; UI in onboarding (optional email/pass + «Вже маю акаунт»), `showLogin()`/`doLogin()`, Settings card «👤 Акаунт» (`accountHTML`: link / change password / logout / other account), dev panel «🔑 Скинути пароль». Multi-device sync: `G.rev` +1 on every `cloudSave`; `cloudSync` loads cloud if its `rev` is higher; `syncOnReturn()` on tab visible/focus; `NET.needSync` blocks uploads until a sync after boot/return so a stale device can't overwrite newer progress; background (hidden) interval saves skipped. Session revoked (`not your player` with `G.acc`) → `sessionExpired()` shows login.

- Week categories (2026-11-01, `sql/week_cats.sql`): `np_week_res` + clean/served/sat/spd, `np_week_claims` PK (player_id, wk, cat); `np_week_top(p_cat)` (parcels|clean|rating|speed, val column); `np_week_claim` returns {wk, place, total, cat}, client loops it. Client tracks `G.week` {served, satSum, clean, spdSum, spdN} via `weekServe()` (called from `rate()` when `FLOW.cid === c.id`).
- Coop (no DB): Supabase broadcast channel `np-coop-<5-digit code>`, event `m`, payload `{t, from:'host'|'guest', to, ...}`. Host (`coopHost`) sends `st` every 1.5 s (free queue), answers `take` with `job`, marks client `c.by='coop'` (patience frozen, staff skip), on `done` calls `staffFinish(pseudoStaff, mist>=2)` and sends `pay` to guest. Guest (`coopJoin`) does a simplified flow in a modal (`coopRender`/`coopAct`, acts `cp*`), pings every 5 s; host drops a silent peer after 25 s (`coopRelease`). UI: Онлайн → «🤝 Кооператив» (`coopHTML`). `NET.sb` = shared supabase-js client.

## Game model (quick map)
- Save `G` (localStorage `np-save-v1`, cloud every 60 s / day end / tab hidden). New fields: add to `newGame()`; `migrate()` fills them in old saves.
- Day: 08:00–20:00, `MIN_PER_SEC` = 1.8 game minutes per real second, speed ×1/×2/×3. Trucks: 08:00 and 13:00 bring parcels (`truckArrive('m'|'d')`), 18:00 takes outgoing ('e'). `endDay()` pays salaries, finishes training, returns parcels stored ≥5 days, shows summary; night = management.
- Parcel states: truck → pile → cell → (issued, removed); outgoing → loaded → (gone with evening truck). Cells: small racks `1-01…` (cap 3, sizes Конверт/S/M), `Г-01…` габарит (cap 2, L/XL). `targetCell()` picks the cell.
- Clients `G.queue`: kind get/send, patience bar; player serving = `FLOW` (not saved): get = phone search → fetch from cell → pay (card / cash with change) → give; send = per item pack (+bubble wrap for fragile) → weigh → city, then pay → print TTN.
- Regulars `REGS` (unlock by level, hearts 0–5 raise tips), staff (roles issue/accept/store/rest, lvl 1–5, training costs 400×lvl, front staff need windows), upgrades `UPS` (start, costs, need level).
- Rendering: full `render()` on `dirty`, postponed while a pointer is down so taps aren't lost; `liveUpdate()` updates clock/patience bars.
- Counter situations (get clients, `specialGet`): `c.inspect` (open before paying → refuse → `returnParcel` to sender), `c.redir` (city/person/back → `redirectParcel`, fee `REDIR_FEE`), `c.proxy` (doc/app legit vs noDoc/wrongName/expired fraud), `p.lost` (cell empty → search grid). Get steps from `getSteps(c)`; send items with `val` (from `ITEMS[].v`) get a 'value' step + `valFee`.
- Barcode scanner: `bcHTML(code, scanAct, id)` + hold/hover ~0.35 s → `act(scanAct)`. Used for pile take, cell contents (`pickscan`), client app code (`appscan`).
- Day events (`rollDay`): `EVENTS` every 7th day (`EV_CYCLE` by day%28) + random sale, eve = queue to door; `WEATHER` flow multiplier; inspection `G.insp` (scores clean/speed/errors, bonus); outage `G.outage` → `manualMode()` (paper journal, no scanner/cards, flashlight overlay `#dark`), `UPS.gen`. Hall dirt `G.dirt` + 🧹 clean; store staff clean when idle.
- Progression: `G.tasks` (3/day from `TASK_T`, `countTask(k, n, set)`), `ACH` + `checkAch()`, `RANKS`/`G.rank` (promote in «Кар’єра» tab, daily bonus), extra branches `G.others` (snapshots of `BR_KEYS`, switch at night, auto-sim in `simOthers()` at day end), decor `G.decor` (`WALLS`, `DECOR` give patience/sat/tips), staff `traits`/`mood`/`fat` (`staffMul`), 💵 bonus.
- Online extras: visits (`showPlayer`: hall preview + reviews + 🎁), gifts arrive as parcels named after the player → special client 🙋 → `giftResult`/`applyGift`; weekly contest (`weekParcels`, claim on boot → badge in `G.badges`); announcements (`G.seenAnn`); globals (`NET.gev`, `NET.gweather`, insp/outage flags).
- 3D hall: `sceneEl()` mounts `Hall3D` into `#scene` (class `s3d`) when `want3D()` (setting `G.settings.s3d`, toggle «🧊 3D зал» in Settings; falls back to the old 2D emoji strip without WebGL). `updScene()` → `Hall3D.sync()`; game data reaches the module only via bridge `window.NP3` (g, act, manual, ev, tab, paused, door, beep, angry, DECOR, WALLS, WEATHER, TIERS). Module draws: counter with 1–4 windows (operators = player + issue/accept staff), clients as figures with emoji heads (path street→door→queue spot/chair/window, leave carrying box/receipt, 😠 if angry), store staff walking between racks, racks/габарит/pile/outgoing boxes from `G.parcels`, upgrades (chairs, coffee, AC, locker, gen, ads, tier plate, scanner), all `DECOR` (cat wanders, tap = meow), dirt decals, rain/snow on the street, outage darkness + torch light, inspector 🕵️, balloons on events. Tap a free client = `act('serve')`; drag = rotate, ＋/－/⟲ buttons. `Hall3D.screenOf(cid)` gives screen coords for Playwright tests (headless needs `--enable-unsafe-swiftshader`).
- v5 mechanics (2026-11-01): send items may have `cod` (post-payment, `codFee`, step 'cod'), `intl` country (`COUNTRIES`, steps ban→pack→weigh→decl→country, `BAN_ITEMS` with `why`, `intlPrice`), refused items `it.refused`, all refused → step 'allref'. Send steps come from `itemSteps(it)` and advance via `advItem(c, from)`. Get specials: `c.claim` (damage act, step 'claim', carrier if box crushed/wet, sender if box ok & no wrap → `finishClaim`), `c.codArg` (client disputes COD, step 'codchk'; giving in → `FLOW.codLess` shortage), `c.lockfix` (locker error E-03/E-07/E-12, step 'lock' → `finishLock`), `c.biz` (business courier, steps bulk→bulkw→print → `finishBiz`).
- Cash: `G.today.cashIn` (cash registered, full TTN sum) and `G.today.short` (wrong change taken, COD given in, staff errors). `endDay` → `makeCashCheck` → `G.cashChk` (persisted, reshown on boot) → modal `showCashCheck`/`cashResult` (acts cashpick/cashdone) → then day summary. No cash → shortage deducted silently.
- Locker reworked: parcels state 'locker' (cap `lockerCap()` 12/20/30), loaded on Store tab (`lockerLoadOne`, act lockload) or by idle store staff, picked up in `tick()` (+12 ₴). Business contracts `BIZ`, `G.biz` {id:{since,strikes}}, `G.bizToday` spawns at random time; 3 angry visits = contract cancelled; signed in Career (bizsign/bizend), max `bizMax()` = 1 + tier.
- Seasons by real date (`seasonNow()`: prebf from 15.11, bf from Black Friday−2 to Cyber Monday, ny 10–31.12) stored in `G.season` at day start: flow/truck/patience multipliers, peak bonus 400 ₴ if ≤2 angry. Winter decor (`DECOR` with `win:1`: tree, garland, snowman, presents) sold only 15.11–15.02 (`winterShop()`); regulars with ≥3 hearts give a holiday gift once per season (`regGift`).
- Districts `DISTRICTS` (center/sleep/private/uni/industrial: items, get share, card share, patience, income) — `G.district` (in `BR_KEYS`, null until the player taps the map in Career; can't change), new branches pick district on the SVG `cityMap()`; up to 4 extra branches (`BRANCH_COST`, `BRANCH_LVL`, `brRank`). Streak by real date (`streakTick` at startDay), monthly goals `MGOALS` → `G.month` (baseline per stat, `checkMonth()` at endDay).
- 3D back rooms: behind the hall back wall (now `R.sep`, hidden in non-hall views; doorway x=6.2): warehouse (reserve racks, sorting conveyor, pile `PILE`, out cart `OUTCART`), roll-up gate at x=7.1/z=−7.9 with dock light, truck (`buildTruck`, states away/arriving/docked/leaving from `G.truck`, boxes = parcels 'truck' or 'loaded', driver), packing zone, kitchen (tired store staff sit with ☕), toilet (occupied sign). Store staff route through doors (`routeTo`, `chooseSpot`). Camera modes `VIEWS` hall/back/all (buttons 🏢 📦 🗺️, `Hall3D.setMode`); Store/Ramp tabs show the 3D scene in 'back' mode automatically. Tap the docked truck → `act('unload3d')`.
- Atmosphere: animated hall `#scene` (persistent element re-attached into `#sceneSlot`, `updScene()` every tick), sounds `sDoor`, `sPrinter`, `sayNext` (speechSynthesis uk), ambient noise (`AMB`), settings toggles sound/ambient/voice.
